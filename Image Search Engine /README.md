# 🖼️ Image Search Engine

A simple and responsive **Image Search Engine** built with **HTML, CSS, and JavaScript**, integrated with the **Unsplash API**.  
Search for any keyword and instantly view high-quality images with smooth UI.

---

## 🚀 Live Demo
[Live Demo → Image Search Engine](https://imagesearchenginerevanthreddy.netlify.app/)

---

## ✨ Features
- Search images using **Unsplash API**  
- Displays multiple results in a clean grid layout  
- Responsive and mobile-friendly design  
- Lightweight and fast — pure frontend project  

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **API:** Unsplash API
