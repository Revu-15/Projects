# 🌦️ Weather Tracker App

A simple and responsive **Weather Tracker App** built with **HTML, CSS, JavaScript**, and the **Unleash API**.  
This app allows users to search for any city and view real-time weather details like temperature, humidity, and conditions.

---

## 🚀 Demo

[Live Demo → Weather Tracker App](https://wheatherapprevanthreddy.netlify.app/)

---

## 🚀 Features
- Search weather by city name  
- Real-time data fetched from **Unleash API**  
- Displays temperature, humidity, and weather conditions  
- Responsive design for desktop and mobile  

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **API:** Unleash API
