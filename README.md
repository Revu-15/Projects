# 💻 My Web Projects Portfolio

This repository contains some of my front-end projects showcasing my skills in **HTML, CSS, JavaScript**, and API integrations.  
All projects are **responsive, interactive**, and **deployed online**.

---

## 1️⃣ Weather Tracker App

Track real-time weather for any city using **Unleash API**.  

**Live Demo:** [Weather Tracker App](https://wheatherapprevanthreddy.netlify.app/)  

**Features:**
- Search weather by city name  
- Displays temperature, humidity, and wind speed  
- Responsive design for mobile and desktop  

**Tech Stack:** HTML, CSS, JavaScript, Unleash API

## 2️⃣ QR Code Generator

Generate and download QR codes from any text or URL.  

**Live Demo:** [QR Code Generator](https://qrcodegenratorrevanthreddy.netlify.app/)  

**Features:**
- Generate QR codes instantly

- Responsive and lightweight UI

## 3️⃣ Image Search Engine

Search and display high-quality images using **Unsplash API**.  

**Live Demo:** [Image Search Engine](https://imagesearchenginerevanthreddy.netlify.app/)  

**Features:**
- Search images by keyword  
- Displays results in a grid layout  
- Mobile-friendly and responsive design  

**Tech Stack:** HTML, CSS, JavaScript, Unsplash API

## ⚡ How to Run Locally

1. Open any project’s "index.html" in your browser.

## 🔑 API Setup (if required)

Weather Tracker: Replace "YOUR_API_KEY" in script.js with your Unleash API key

Image Search Engine: Replace "YOUR_ACCESS_KEY" in script.js with your Unsplash API key
