# 🔳 QR Code Generator

A simple and user-friendly **QR Code Generator** built with HTML, CSS, and JavaScript.  
Generate downloadable QR codes from any text or URL quickly — perfect for sharing links, Wi-Fi credentials, event info, and more.

---

## 🚀 Live Demo
[Live Demo → QR Code Generator](https://qrcodegenratorrevanthreddy.netlify.app/)

---

## ✨ Features
- Generate QR codes from any text or URL input  
- Download generated QR as PNG  
- Responsive, mobile-friendly UI  
- Lightweight and fast (no backend required)  

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **QR Library:** qrcode.js (or equivalent)
